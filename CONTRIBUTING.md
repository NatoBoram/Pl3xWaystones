# Contributing

## Icons

Icons are the PNG images in [`src/main/resources/assets/pl3xwaystones/icons/`](./src/main/resources/assets/pl3xwaystones/icons/), named after the ID of their block, like `mossy_waystone.png`, `red_sharestone.png` or `warp_plate.png`. Blocks without an icon use `waystone.png`.
